# AWS-S3-Security-Configuration
AWS S3 Security Configuration

## Project Overview
This project demonstrates beginner cloud security practices using AWS S3.

## Features
- Secure S3 bucket setup
- Block Public Access configuration
- File upload testing
- Access restriction validation

## Tools Used
- AWS S3
- IAM
- Cloud Security Concepts
- GitHub

## Objective
To understand how to secure cloud storage using AWS S3 security configurations.

## Security Validation
Public access was successfully blocked and unauthorized access returned "Access Denied", confirming secure bucket configuration.
